- **Rate edits are found by the song's name.** A map set with one song at several rates, each with its own audio (e.g. DEVILS NEVER CRY at 0.9, 0.95, 1.05...), used to show each rate titled only by its difficulty ("0.9"), so searching for the song found nothing in Til' Death and Rebirth. Each one is now "DEVILS NEVER CRY [0.9]" and so on, in every look; dan packs keep the pack's name first too. Packs whose difficulties are named "Artist - Title" keep those names. Only those sets are read again on the next start, and your scores stay with them.
