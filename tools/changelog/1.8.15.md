- **Skin settings to share.** Options > Export skin settings writes everything Customize gameplay keeps for the noteskin in use (notefield, columns, notes, receptors, lane cover, LN tail, stage hint, lighting) to `Save/VSRGHub/skins/<noteskin> (4K).vhskin`, a small file to send to someone; Import skin settings puts one of those onto the noteskin you're using.
- **Skins that come set up.** A skin can carry that file in its own folder, as `vsrghub-4k.vhskin` or `vsrghub-7k.vhskin` (`vsrghub.vhskin` for both): whoever installs the skin gets its notefield as its maker had it the first time they play with it, nothing to set by hand. Reset in Customize gameplay goes back to the skin's own settings.
